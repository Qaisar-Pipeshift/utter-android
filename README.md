# Utter

A voice keyboard for Android that types what you say, using **your own** speech-to-text server.

- Works next to Gboard and Samsung Keyboard: switch to Utter, speak, the text lands in the field, and you are back on your keyboard.
- Live text while you speak, optional LLM clean-up, history, and a recording status in the notch (Android 16 Live Updates).
- No background work: Utter only runs while its panel is on screen.

Nothing in this repository points at a particular server. The server URL and API key are entered on the phone at first run.
